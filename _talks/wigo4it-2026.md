Bij de kennisdelingschapter van Wigo4it in Den Haag vertelde ik over
developer.overheid.nl. Over hoe wet developers tools bieden waarmee je software
bouwt die direct voldoet aan de standaarden.

## Standaardiseren voorkomt discussies

Standaardiseren voorkomt ellenlange threads in PR's en maakt software
voorspelbaar. Naast alle kennis bieden we ook tools waarmee je iteratief checkt
of je nog compliant bent.

Aan bod kwamen:

- **Kennisbank & Open Source Catalogus**: vindbare open source dankzij
  `publiccode.yml`
- **API Catalogus & API Design Rules**: controleer je API met de `don-checker`
  via CLI, web-app of CI/CD
- **AI skills**: kennis over overheidsstandaarden direct in je AI-agent
- **Schema-register** (bèta): een plek waar we je in de toekomst alle
  JSON-Schema's van de overheid vindt
