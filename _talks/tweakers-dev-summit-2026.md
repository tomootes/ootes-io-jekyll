Op de Tweakers Dev Summit in De Fabrique, Utrecht, vertel ik over
developer.overheid.nl en waarom ik standaarden ben gaan zien als een manier van
samenwerken. Ze helpen de overheid om eenduidiger te ontwikkelen, en ze zijn ook
instructies voor je coding agent, zodat die niet uit de bocht vliegt.

## Eilandjes, maar dezelfde taken

Overheidsorganisaties werken nog te vaak als aparte eilandjes, terwijl ze
dezelfde uitvoeringstaken hebben: Woo, formulieren, inloggen met DigiD, security
en toegankelijkheid. De macht is verdeeld, dus techniek kun je niet opleggen.
Ons antwoord: tooling bouwen die zo bruikbaar is dat je vanzelf compliant wordt.

Dat doen we langs drie pijlers:

- **Open source samenwerken**: vindbare software dankzij `publiccode.yml`, en
  een agent skill die je repo klaarmaakt voor open source
- **Open standaarden & tooling**: de API Design Rules, met de `don-checker` in
  je terminal of CI/CD, en als skill voor je coding agent
- **Overheidsbrede services**: code.overheid.nl, één git forge voor de hele
  overheid
